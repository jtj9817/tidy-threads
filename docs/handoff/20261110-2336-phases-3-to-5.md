## Gotchas learned this session

All are also in `TODO.md` agent notes:

- `tools/autotest.py` reads its config from the environment: run `source tools/env.sh` first. `env.sh` now exports
  the identity and `MOD_DEPS=adaptive.storage.framework`.
- Scenario names can't contain commas, so drop the comma from the plan's title (`T2 Build a wardrobe VFE not active`).
- A pass-through building holds items only with `surfaceType Item` (`GenPlace`).
- `Graphic_Multi` swaps `drawSize` for east/west when the east texture differs from north (`Graphic.MeshAt`).
- `AutoTest.Init` runs from `TT`'s `[StaticConstructorOnStartup]`, not the Mod constructor (it creates a GameObject).
